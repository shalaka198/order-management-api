# order-management-api

## Run locally

1. From the project root, run:
   dotnet run --project [OrderManagementApi.csproj](http://_vscodecontentref_/9)

2. Open Swagger UI:
   https://localhost:7083/swagger
   or
   http://localhost:5027/swagger

## API docs endpoints

- OpenAPI document (JSON): /openapi/v1.json
- Swagger UI: /swagger

Notes:
- Swagger UI and OpenAPI endpoint are mapped in Development.
- ASPNETCORE_ENVIRONMENT should be Development when running locally.
